## 数据兼容与回滚

新代码接受旧数据。翻译目录与分类索引新增可选 `failed_repository_ids`，当前 Schema/校验器同步更新。只有历史 failed_count、没有 ID 的缓存，离线时保留不超过 pending 数的旧计数；第一次在线尝试起转为实际观测的失败 ID，未知历史失败仍属于 pending，不推断为成功，也不重复计数。

旧版严格的 1.0.0 Schema 不接受该新增字段。因此生成器、Schema 与校验器必须同版升级；不能将新版产出的数据交给旧版严格校验器。回滚应配套选择升级前的已验证数据提交，或保留本批次新版校验器；不要只回滚代码后继续消费新版数据。Pages 本次按 `deploy_existing` 使用固定数据提交构建，不改写数据分支。
