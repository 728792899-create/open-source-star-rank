## 产品接入路线

1. **正式 UI 迁移已实施。** Astro 业务页面采用原型视觉，接入已有真实榜单、详情、语言和分类数据，保留加载/空数据/失败/陈旧状态。视觉与交互证据见 [UI 验收](../design-qa.md)，GitHub/部署结果见进度记录。
2. **扩展收录与索引。** 当前业务配置为最多 2,000 个持续候选、净增 Top 500、累计 Top 1000；六条数据只属于 UI 原型。分层发现、分段采集、增量刷新、去重、搜索索引和分类需要单独实现，不能把现有榜单称为 GitHub 全量镜像。
3. **说明覆盖与时效。** 展示已收录数量、最近成功时间、各管线健康和完整性；搜索、采集或速率限制失败时保留上一有效快照。以可验证覆盖范围为准，不承诺全站实时无遗漏。
4. **提升选型价值。** 将原型中的用途、部署、平台、资源、许可名称和维护状态接入有来源的信息；未知字段留空，相似项目展示推荐理由。
5. **完善交付与运维。** 区分采集恢复、连续基线重建和榜单更新，记录源码/数据版本与构建产物，演练回滚；以真实数据量度量增量构建成本。

其中未完成项目仍是后续计划，已完成项的发布结果以进度记录为准。当前源码同步、主分支合并、Pages 发布和 Worker/D1 升级是不同交付阶段，状态见 [项目进度](DEVELOPMENT_PROGRESS.md)。
